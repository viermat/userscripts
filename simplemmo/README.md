# SimpleMMO

SimpleMMO web game userscripts.

# [Cemetery Walk](./cemeteryWalk.user.js)

> [!WARNING]
> This userscript is guaranteed to get your account banned and possibly your IP

Cemetery Walk is an undetectable userscript for auto stepping in SimpleMMO. This userscript monkeypatches the document's `fetch` method and spoofs the "travel" request, making the fake auto-step click seem legit to the server. This script is completely undetectable currently.

# [Gravedigger](./graveDigger.user.js)

Gravedigger is a userscript that uses SimpleMMO's public API to imitate the "spy" function that the game offers, but without any in-game cost.
